# Budget Book

Home Assistant Supervisor Add-on port of the [Budget Book](https://github.com/Im-Tim-mI/Home-Assistant_Budget-Book) custom integration (v1.2.1), with the same panel UI and features. This add-on lives in the same repository as the HACS integration.

## Features

- Original panel: Overview, Transactions, Charts, Categories, Budgets, Recurring and Settings tabs.
- Multiple books, transaction edit with time, custom categories, budgets and alerts.
- Recurring entries auto-inserted daily at 09:00.
- JSON import/export, sample data, Auto / English / 繁體中文 / 简体中文.
- Publishes `sensor.budget_book_*` entities to Home Assistant.
- Persistent storage in `/data/budget_book.json`.
